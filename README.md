# 定时应用锁 (AppLock)

一个本地 Android 应用锁:在设定的时间段内锁定指定应用,帮助自己对抗"一刷就停不下来"。

> **本项目由 AI 辅助生成** —— 代码基于 **DeepSeek** 大模型(通过 WorkBuddy 智能体)编写与迭代,非人工逐行手写。详见文末「说明」。

## 功能

- **固定时段锁**:为每个应用单独设定"生效星期 + 起止时间",到点自动把目标应用弹回桌面。
- **多应用多规则**:可为不同应用设置多条独立规则。
- **保护期冷却**:距锁定开始 ≤ 1 小时内,关闭/删除/修改规则需保持前台等待 30 分钟,期间切后台即重新计时(防"顺手拆锁")。
- **锁定中冻结**:规则生效期间,停用/删除/编辑均被禁止。
- **多背景主题**:内置 9 张背景图,九宫格弹窗选择,卡片按背景深浅自动适配半透明配色。

## 使用前的必要设置(红米/HyperOS 用户必读)

由于系统会杀死后台无障碍服务,必须手动完成以下设置,否则无法锁应用:

1. **开启无障碍服务**:设置 → 无障碍 → 定时应用锁 → 打开开关。
2. **省电策略设为「无限制」**:设置 → 应用管理 → 定时应用锁 → 省电策略 → 无限制。
3. **打开自启动**(如有该选项)。

> 覆盖安装新版本后,需重新开关一次无障碍服务。

## 已知限制

- 本地应用锁无法对自己做到绝对强制——拥有设备最高权限者可随时卸载或关闭无障碍。
- 拦截依赖无障碍服务常驻,系统更新/重启后可能需重新开启。
- 仅支持"固定时段锁",不支持"每日时长配额"。
